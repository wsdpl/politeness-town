========================================
        礼貌小镇 - 项目说明
   儿童礼貌教育互动游戏
========================================

【项目简介】
----------------------------------------
礼貌小镇是一款基于 Godot 4.7 开发的儿童礼貌教育互动游戏。
游戏通过 RPG 探索和情景对话的方式，引导儿童在虚拟小镇中
学习问候、请求、道谢、道歉、分享和告别等礼貌用语。

【运行环境】
----------------------------------------
- 操作系统：Windows 10/11 (64位)
- 内存：建议 4GB 以上
- 存储：约 250MB 可用空间
- 麦克风：需要（用于语音识别功能，可选）
- 网络：需要（用于 AI 评分和语音识别，可选）

【快速开始】
----------------------------------------
1. 运行"安装程序.exe"
2. 选择安装路径（默认安装到用户目录下）
3. 勾选"添加快捷方式到桌面"和"添加快捷方式到开始菜单"
4. 点击"安装"按钮等待安装完成
5. 安装完成后可通过桌面快捷方式启动游戏

【游戏流程】
----------------------------------------
1. 注册页面：输入儿童昵称，选择 AI 角色类型
   - 伙伴型 AI（小礼）：温柔亲切，适合年龄较小的儿童
   - 工具型 AI（引导系统）：简洁规范，适合年龄较大的儿童

2. API 设置（可选）：
   - 科大讯飞语音识别：配置后支持语音输入
   - DeepSeek AI 评分：配置后提供智能对话评分
   - 如未配置，游戏将在 8 秒后自动跳过 AI 评分

3. 板块一：礼貌小屋 RPG
   - 使用 W A S D 或方向键移动角色
   - 走近 NPC 后按 E 键开始对话
   - 共 6 个关卡：迎宾问候、玩具请求、礼物道谢、积木致歉、绘本分享、出口告别
   - 包含 3 个互动小游戏：宝箱、积木、绘本

4. 板块二：阳光超市 RPG
   - 两条故事线，每条 3 个 NPC
   - 在超市场景中练习礼貌用语
   - 完成后生成评估报告

5. 结果报告：
   - 雷达图展示各维度得分
   - 星章展示通关成就
   - 详细的评估数据记录

【操作说明】
----------------------------------------
- 移动：W A S D 或方向键
- 对话/交互：E 键
- 跳过对话：空格键或点击对话框
- 语音输入：点击"🎤 说话"按钮开始录音，再次点击停止并识别
- 文字输入：在输入框中输入文字，点击"发送"按钮

【技术栈】
----------------------------------------
- 游戏引擎：Godot 4.7 (GL Compatibility 渲染器)
- 编程语言：GDScript
- 字体：Noto Sans CJK SC、郑格点黑
- 语音识别：科大讯飞 WebAPI (流式听写)
- AI 评分：DeepSeek API
- 安装程序：C# (.NET Framework 4.0, Windows Forms)

【API 配置说明】
----------------------------------------
1. 科大讯飞语音识别：
   - 访问 https://www.xfyun.cn/ 注册账号
   - 创建应用，获取 APP_ID、API_KEY、API_SECRET
   - 在游戏"API 设置"页面填入以上信息
   - 配置后可使用语音输入功能

2. DeepSeek AI 评分：
   - 访问 https://platform.deepseek.com/ 获取 API Key
   - 在游戏"API 设置"页面填入 API Key
   - 配置后 AI 可对儿童回答进行智能评分

3. 未配置 API 时的行为：
   - 语音输入不可用，可通过文字输入进行游戏
   - AI 评分跳过，8 秒后自动进入下一环节

【开发者信息】
----------------------------------------
- 如需修改游戏内容，使用 Godot 4.7 编辑器打开项目
- 导出配置见 export_presets.cfg
- 安装程序源码见 installer/Installer.cs
- 使用 csc.exe 编译安装程序：
  csc /target:winexe /out:安装程序.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll Installer.cs

【注意事项】
----------------------------------------
- 首次启动游戏可能需要几秒钟加载资源
- 语音识别功能需要麦克风权限
- AI 评分功能需要网络连接
- 游戏数据保存在用户目录下的 user:// 路径
- 建议在 1920x1080 分辨率下运行以获得最佳体验
